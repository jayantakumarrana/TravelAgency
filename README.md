# TravelGo — Responsive Website

A responsive travel and vehicle-rental landing page built with plain HTML, CSS, and JavaScript.
The language selector translates the page into English, Hindi, Odia, or Tamil.

## Run
Open `index.html` in a modern browser. No framework or build process is required.

## Project files
- `index.html` — page structure and content
- `style.css` — responsive design, cards, colors, and breakpoints
- `script.js` — mobile navigation and automatic footer year
